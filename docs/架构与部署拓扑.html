二、私有化部署拓扑（企业内网机房 / 企业云 VPC）

🟦 DMZ 区（对外最小暴露）
负载均衡 ×2（主备）Nginx/Keepalived，唯一出入口
企微回调接收仅开放企微 IP 白名单
▼ 防火墙策略：仅 443 端口入站
🟩 应用区（内网）
API 节点 ×3FastAPI + Uvicorn，无状态可横向扩
抢号专用节点 ×1~2独立部署放号定时任务与排队消费，与日常流量隔离
Agent/LLM 节点 ×2编排服务 + 本地开源模型推理（如 Qwen 系列，vLLM）——私有化+等保下数据不出内网
管理后台 ×1
定时任务调度 ×1放号、HR 同步、对账
▼ 防火墙：按端口最小化开通
🟪 数据区（最高防护等级，仅应用区可访问）
PostgreSQL 主 + 从流复制，自动故障切换
Redis 哨兵 ×3
向量库pgvector（随主库）或独立 Milvus
MinIO ×2发票影像，加密存储
备份每日全量 + 实时 WAL 归档，异地/离线备份介质

三、万人抢号的专项设计

环节措施
放号前号源预写入 Redis；静态资源提前预热；网关预扩容
放号瞬间请求进入 Redis 队列排队按序消费；号源扣减用 Lua 原子操作防超约；单用户限流（每秒 1 次）+ 全局限流
放号后异步落库（先 Redis 成功 → 队列异步写 PG）；HIS 回写走补偿任务，失败自动重试+告警
等保二级要点映射：身份鉴别（SSO+双因素可选）、访问控制（RBAC+网络分区）、安全审计（全量日志集中存储 ≥180 天）、数据完整性保密性（传输 TLS + 存储 AES 加密）、备份恢复（每日备份 + 恢复演练）。
三条铁律：① LLM 本地部署，健康数据与制度文档不出内网；② 所有外部系统经适配器隔离，任何一个挂掉系统主流程可降级运行；③ 号源写入只有 Redis 原子扣减一条路径，杜绝超约。
